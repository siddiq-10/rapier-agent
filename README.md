# Rapier – Market Intelligence Agent

**Rapier** is an autonomous AI agent that gathers, analyzes, and delivers competitive market intelligence for the payments and fintech industry.

It is specially designed to track key players such as:
- Razorpay
- Cashfree Payments
- PayU India
- Instamojo
- CCAvenue
- Stripe
- PayPal
- Adyen

---

## Features

- Autonomous tool-using agent (news fetching + web search + memory)
- Real-time news gathering using DuckDuckGo
- Structured competitive analysis
- Memory of previous insights
- Clean Streamlit interface for interaction

---

## Tech Stack

- **Python**
- **Groq** (`openai/gpt-oss-20b`)
- **DuckDuckGo Search** (real news)
- **Streamlit** (UI)
- Simple memory system (JSON)
